# Durch die Wolken

Wie ferne doch Gott manchmal schein! Gehen meine Gebete denn wirklich weiter als bis zur Zimmerdecke, wo ich doch gerade so dringend Hilfe brauche? Interessiert sich Gott überhaupt für mich? Ein Loblied auf das Klagen, das bei Gott seinen Platz hat und ankommt -- und auf den Gott, der die Klage hört und sich über seine Menschen erbarmt.
